# Android 端源码骨架

这个目录提供一个 Android 原生客户端的最小工程，包含：

- 前台服务常驻连接中继服务
- 设备注册与共享密钥
- `MediaProjection` 录屏授权与 JPEG 帧上传
- 无障碍服务入口，可用于执行远端点击、滑动、返回、Home、任务键和文本输入

## 打开方式

1. 用 Android Studio 打开 `android-agent` 目录。
2. 安装 Android SDK 35 和 JDK 17。
3. 编译后在手机上安装。
4. 在系统设置中开启该应用的无障碍服务。
5. 在应用内点击“开始远控服务”，并授权录屏。

## 当前状态

当前已经接通：

- Android 连接中继并注册设备
- Android 通过 `MediaProjection` 回传手机屏幕 JPEG 帧
- 收到远端点击、滑动、返回、Home、任务键和文本输入后通过无障碍服务执行

这已经能支持“手机不连接电脑，仅通过联网和中继服务被浏览器控制”的主链路，但仍然不是生产版。剩余缺口主要是：

1. 视频流现在是低帧率 JPEG 上传，不是 WebRTC 或 H.264。
2. 长按、多指手势、剪贴板同步、文件传输和音频回传还没做。
