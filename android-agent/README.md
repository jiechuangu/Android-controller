# Android 端源码骨架

这个目录提供一个 Android 原生客户端的最小工程，包含：

- 前台服务常驻连接中继服务
- 设备注册与共享密钥
- 无障碍服务入口，可用于执行远端点击/返回/Home
- 后续接入 `MediaProjection` 的扩展位

## 打开方式

1. 用 Android Studio 打开 `android-agent` 目录。
2. 安装 Android SDK 35 和 JDK 17。
3. 编译后在手机上安装。
4. 在系统设置中开启该应用的无障碍服务。

## 当前状态

这是可继续开发的骨架，不是已经补完的生产版手机客户端。当前已经接通：

- Android 连接中继并注册设备
- 收到远端 `pointerdown` 后通过无障碍服务执行点击
- 收到 `Escape/Home` 后执行返回和回桌面

要实现“电脑实时查看并操控手机”，还需要继续补两块：

1. `MediaProjection` 录屏授权与帧编码上传。
2. 更完整的手势桥接，例如拖拽、长按、输入法文本注入。
